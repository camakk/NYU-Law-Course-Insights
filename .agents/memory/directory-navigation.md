---
name: Directory return navigation
description: Product expectations for returning from a detail page to a directory.
---

Returning from a professor detail page must restore the exact directory filters, sorting, and scroll position, using either the browser Back button or the page's own back link. Opening a detail page starts at the top.

**Why:** The user has repeatedly requested that exploring an individual professor not lose their place or comparison settings in the directory.

**How to apply:** Preserve the actual originating directory view on both return paths. Keep a safe directory-link fallback for profiles opened directly, without an originating directory history entry.
